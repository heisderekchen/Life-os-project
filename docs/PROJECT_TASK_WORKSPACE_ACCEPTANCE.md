# 项目与任务统一工作台｜交付与验收

日期：2026-10-19。范围：独立 Life OS 的 `/workbench/`，项目与动态任务入口统一。用户已批准关系图／列表联动预览并授权部署。

## 交付

- 联动、列表、关系图三种视图，共用搜索、项目／类型／状态筛选、排序及选中状态。
- 项目 → 主题 → 任务层级，未归类任务保留在未分类／收件箱。列表可按层级或平铺；状态、类型、更新时间及截止日期可查。
- 主题可创建、改名和删除；任务项目／主题／状态／类型／截止日期可保存。删除主题保留任务；换项目自动清除不兼容的旧主题；跨项目主题写入被拒绝。数据库触发器同时保护旧导入工具的项目重关联：同项目保留主题，跨项目清除不兼容主题。
- 图内每主题默认最多显示七条任务和“更多任务”，选中的其他任务也会显示；节点使用原生键盘按钮。缩放、收起、完整任务详情、原有周期／执行和项目管理均保留。
- 0099 为增量迁移，无旧记录自动分类。JSON 备份导出／恢复包含主题并兼容旧备份，周期续建保留主题和类型。
- 登录页脚本拼接处补分号，防止内嵌设置脚本使登录脚本整体无法解析。
