## 交付

- 联动、列表、关系图三种视图，共用搜索、项目／类型／状态筛选、排序及选中状态。
- 项目 → 主题 → 任务层级，未归类任务保留在未分类／收件箱。列表可按层级或平铺；状态、类型、更新时间及截止日期可查。
- 主题可创建、改名和删除；任务项目／主题／状态／类型／截止日期可保存。删除主题保留任务；换项目自动清除不兼容的旧主题；跨项目主题写入被拒绝。数据库触发器同时保护旧导入工具的项目重关联：同项目保留主题，跨项目清除不兼容主题。
- 图内每主题默认最多显示七条任务和“更多任务”，选中的其他任务也会显示；节点使用原生键盘按钮。缩放、收起、完整任务详情、原有周期／执行和项目管理均保留。
- 0099 为增量迁移，无旧记录自动分类。JSON 备份导出／恢复包含主题并兼容旧备份，周期续建保留主题和类型。
- 登录页脚本拼接处补分号，防止内嵌设置脚本使登录脚本整体无法解析。

## 2026-10-19 用户反馈修正：父子关联、菜单与排序

- 原因：统一工作台按任务自身项目/主题分组，遗漏了已有的 `parentTaskId`。未单独设置项目的子任务因此被误放入旧“收件箱”。现按记录的父子链计算展示归属，明确单独设置的归属保留；不回填或批量改写数据库。原 API 记录继续用于编辑，重命名只更新名称。
- 关系图与层级列表展示任务及多级子任务，支持逐级展开/收起；筛选命中子任务时保留同一有效项目/主题分支内的父任务上下文，不将上下文计入匹配数量。明确设置为不同项目/主题的记录仍在各自分支作为根节点展示，平铺路径与概要保留父任务关联，不改写其显式归属。平铺行与任务概要显示父任务路径，提供查看父任务操作。真正未归属项目的记录改称“未分配项目”。孤立/循环关系保留记录并防止无限遍历。
- 图节点和层级行均支持右键菜单；同一组操作通过可聚焦的“快捷操作”按钮提供给键盘/触屏用户。按节点类型开放重命名、新建主题/任务/子任务、任务归属编辑、完成/重新打开、完整详情与展开/收起。主题删除继续使用原有确认并保留任务；合成分组不可重命名/删除。
- 五个可见列支持表头切换排序，使用 `aria-sort` 公布方向，与原排序控件共用状态。类型加入可排序字段；状态按待办、进行中、完成、取消排序；空日期/类型在升降序均留在末尾。
- 198 项测试及类型检查通过；新增组件/模型测试覆盖继承展示与原记录保留、循环/缺失父任务、筛选祖先上下文、五列双向排序、右键重命名和创建时传递父任务 ID。浏览器复验使用真实 Node/SQLite 接口的隔离合成数据库，未修改生产任务。
