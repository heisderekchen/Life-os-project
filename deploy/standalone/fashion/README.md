# 鞋履设计工作台 · 本地预览

面向手机碎片时间的「检索 → 核查 → 交付」流程。默认进入工作台首页，包含「检索任务」「交付结果」两个模块；左下角圆形三横线按钮向右展开菜单，可切换工作台与两个模块。桌面沿用同一资料与菜单，增加多列浏览空间。视觉采用用户选定的第二版蓝灰方向与 cobalt 操作色。旧版 `../shoe-intelligence` 未修改。

## 启动

需要支持原生 `fetch` 与 `node:test` 的现代 Node.js。首次使用先安装依赖，再启动：

```sh
npm install
npm start
```

打开 <http://127.0.0.1:4176>。可通过 `SHOE_TASK_PORT` 修改端口；服务默认只监听本机。默认提供 `demo-a`、`demo-b` 两个独立体验账号。设置 `SHOE_TASK_USERS` 为「账号到密码」的 JSON 对象后，改用账号密码登录；请通过运行环境传入真实配置，勿提交到仓库。

任务与交付按账号保存在 `.data/<账号>.json`，重启保留数据，登录会话需要重新建立。重启时未结束的检索会标记异常，可重试。本版本用于本地评审，尚未生产部署，也未提供正式多人托管方案。

## 使用

首页去掉头部背景图，仅显示 2 张缩小的 AI 生成装饰性 WebP，用于模块封面，不进入检索结果或交付证据。圆形入口向右展开菜单，可点击外部或按 Escape 收起，支持键盘操作与再次打开；减少动态效果偏好会禁用菜单动画。

1. **新建任务**：填写鞋型、品牌或设计方向，选择近 7/30/90 天或不限。常见中文鞋型会补充英文检索词。图片检索默认不限时间；发布日期未知时保持未知，选择近7/30/90天会排除此类图片。
2. **指定网站（可选）**：最多三个域名。此项限定搜索引擎已收录的站点内容，不代表网站直采、全站抓取、登录内容访问或自动监控。
3. **核查结果**：打开原始来源，对照鞋款、图片与日期；分别设置待核查、已核查、存疑或已排除。已核查必须填写依据，核查通过后才能选入交付。未知日期保持未确认；限定时间时不纳入未知日期。
4. **生成交付**：至少一条已核查且已选入的结果才能生成。交付保存当次结果快照与核查依据；可导出 CSV，或使用浏览器「打印 / 保存 PDF」。修改时先重新打开任务，再生成新的交付。

检索先保存任务，离开页面后可回来查看。异常保留任务并提供重试。空结果可调整条件。历史素材通过独立入口体验，并持续标注为历史示例。

## 手机外网临时预览

`npm run start:preview` 启动直接进入的手机试用实例（本机端口 4177），无登录页、账号或密码。每个浏览器自动获得独立的临时会话，任务保存在 `.data/phone-preview/`；刷新同一浏览器可继续操作，清除 Cookie 或服务重启后会开始新的会话。外网通过临时 Tunnel 访问，电脑休眠、服务或 Tunnel 停止后不可访问，不代表正式部署。此免登录行为仅用于手机试用实例；原本的本机工作台登录模式保持原样。

## 关注来源预览
通过 `?view=new` 直接进入新建检索页。原生滑杆控制实际查询计划：聚焦仅初始目录内的选中来源及补充域名；均衡增加 Google News 相关新闻；广泛再增加 Bing 公开网页。初始目录为 Miu Miu、Camper、Vogue、NET-A-PORTER、Mytheresa 的公开索引页面，不代表平台 API 或全站采集接入。社交社区与独立图片库未接入。多渠道不再提前停止，去重后按发布日期倒序，三档候选上限为24/48/72，不承诺命中量。当前仍是一页一张预览图。


## 2026-10-19 图片流程修复与浏览器验收

继续本目录与现有 4177 临时预览，未新建项目，未合并或生产发布。

- 使用真实公开图片检索；逐条读取原页面，核对页面标题关键词与同一图片路径。无法读取的来源、失效图片、关键词冲突、常见转售与转载来源会被过滤，空结果不补历史素材。
- 图片经二进制类型检查后保存在本地私有缓存，按 SHA-256 去重。浏览器可点击大图并打开原始来源。失效图片取消选入；重新检索保留同一图片的核查记录，变化的图片重新核查。
- 聚焦限定选中站点；均衡增加公开图片；广泛扩大公开图片候选核对范围。当前单次最多保留8张，来源日期未知时保持未知，限定时间将排除此类图片。
- “导出图片与来源”实际下载离线 HTML，包含嵌入图片、逐张原始来源、原图地址、编号、SHA-256和核查依据；CSV 同步保留对应字段。生成交付与图片包导出时再次核对来源与缓存。
- 来源可追溯不代表获得商用授权。

每轮关键词、问题、修复、复测及截图见项目 `output/browser-acceptance-2026-10-19/`。自动测试为16项；功能结论以该目录的实际浏览器记录为准。内置浏览器允许 HTTP/HTTPS，但禁止打开 file:；实际下载后的文件通过内容、图片解码与哈希核对，没有声称浏览器离线重开通过。物理手机、Safari及打印/PDF未在本轮验收。
